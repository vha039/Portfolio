    Terms and concepts

    #
    Semantic model
    Tables, relationships and calculation rules that give data a shared business meaning. The model the reports are built on.
    Data grain
    What one row represents, for example an organisational unit in a particular period.
    Dimension
    Information used to narrow down or group facts, such as time, organisation or category.
    Star schema
    A modelling pattern in which fact tables connect directly to shared dimensions, with no layers of lookups between the dimensions.
    Filter context
    The selection a calculation applies to. If you change the selection, both the numerator and the base can change.
    DAX
    Data Analysis Expressions. The calculation language in Power BI, used for measures and calculated columns, among other things.
    Power Query
    A tool for fetching, processing and combining data before it is used further.
    DRG
    Diagnosis-related groups. DRG points are used as a measure of activity and are not a count of patients.
    Behavioural parity
    That two implementations behave the same way within a set tolerance under an explicit, limited set-up. In running text called conformance. It is not a measure of forecast accuracy.
    Holdout
    Data that is held out from model fitting and used to examine the result on other observations.
    Rolling validation
    The model is fitted on data up to a point in time and tested on the period after. This is repeated for several points in time.
    Proxy
    An indirect signal used when direct measurement does not give a good enough basis. The assumptions must be open to examination.
    Price level
    The basis that makes amounts from different price years comparable. An explicit factor is needed before the amount is converted.
    Coding agent
    A language model with tools that can examine and change code within a defined task. A human assesses integration and use.
    Management BI
    Reports that bring together figures on finance and operations, so that managers can follow developments.
    VBA
    The programming language for macros and automation in Microsoft Office programs such as Excel.
    FTE
    Full-time equivalent, a measure of workload. One FTE corresponds to the work of one full-time position for one year (Norwegian: årsverk).
    Period allocation
    Distributing an amount or quantity across the periods it relates to.
    Snowflake schema
    A modelling pattern in which the dimensions are split into several tables with lookups between them. An alternative to the star schema.
    Fact table
    A table of measurements, for example amounts, DRG points or days of absence, linked to shared dimensions.
    Baseline model
    A simple model used as a point of comparison when other forecasting models are assessed.
    Acceptance criteria
    Requirements that must be met for a delivery or change to be accepted.
    XGBoost
    A machine learning method that combines decision trees. New trees are built to reduce the errors in the combined estimates.
    GAM
    Generalised additive model. A statistical model in which the relationship between a variable and the outcome can be described with a smooth curve.
    SARIMAX
    A time series model that can use past values, seasonal patterns and other explanatory variables.
    Token
    Units used to count how much content language models process. Registered processing can include the same content several times.

    Source types

    #

    Role, deliverable and status on the deliverable pages are my own account of the work, with team and responsibility delimited where it matters. Other source types are labelled where they occur.

    Own account

    My description of my own work, collaboration and status. Appears without a label.

    Inspected artefact

    A limited observation of structure or code, such as the scope of the BI model. It does not say who wrote what.

    Reported result

    A stated result or use, without any claim of independent reproduction.

    Editorial reconstruction

    Newly written diagrams and explanations of relationships, like the simplified figures on the project pages. They are not historical decision records.

    Synthetic illustration

    New fictitious data and calculations that explain a mechanism. They do not run the original system.
